② Query Request Workflow (POST /knowledge-bases/{kb_id}/query/)
sequenceDiagram autonumber actor User participant API as FastAPI participant KBM as KB Manager participant RAG as LangChain RAG participant OAI_E as OpenAI Embeddings participant VS as Vector Store (FAISS / Chroma) participant OAI_G as OpenAI LLM User ->>+ API : POST /knowledge-bases/{kb_id}/query/\n{ "query": "What is the refund policy?" } API ->> KBM : validate KB exists, read metadata KBM -->> API : KB confirmed ✓ API ->>+ RAG : get_rag_response(query, kb_id) RAG ->> RAG : load all .txt docs from data/{kb_id}/documents/ RAG ->> RAG : split into 500-char chunks (50 overlap) RAG ->>+ OAI_E : embed all chunks + embed query OAI_E-->>- RAG : chunk vectors + query vector RAG ->>+ VS : similarity_search(query_vector, k=5) VS -->>- RAG : top-5 most relevant chunks RAG ->> RAG : build prompt:\n"Use this context: {chunks}\nAnswer: {query}" RAG ->>+ OAI_G : generate(prompt) OAI_G-->>- RAG : generated answer text RAG -->>- API : response_text API -->>- User : 200 OK\n{ "kb_id", "query", "response" }
③ TruLens Evaluation Workflow (POST /knowledge-bases/{kb_id}/evaluate/)
sequenceDiagram autonumber actor User participant API as FastAPI participant RAG as LangChain RAG participant OAI_G as OpenAI LLM participant TRUL as TruLens Provider participant OAI_J as OpenAI (Judge) participant DB as eval_records.json User ->>+ API : POST /knowledge-bases/{kb_id}/evaluate/\n{ "query": "..." } API ->>+ RAG : get_rag_context_and_response(query, kb_id) RAG ->> OAI_G : generate answer OAI_G-->> RAG : answer text RAG -->>- API : (response_text, [context_chunks]) Note over API,TRUL: RAG Triad Evaluation (3 LLM judge calls) API ->>+ TRUL : relevance(query, response) TRUL ->> OAI_J : "Is this response relevant to the query? Score 0-1" OAI_J-->> TRUL : answer_relevance score TRUL -->>- API : 0.94 API ->>+ TRUL : context_relevance(query, each_chunk) TRUL ->> OAI_J : "Is this chunk relevant to the query? Score 0-1" × N OAI_J-->> TRUL : per-chunk scores → averaged TRUL -->>- API : 0.87 API ->>+ TRUL : groundedness(context, response) TRUL ->> OAI_J : "Is every claim in the response supported by the context?" OAI_J-->> TRUL : groundedness score + reasons TRUL -->>- API : 0.91 API ->> DB : save EvalRecord\n{ id, timestamp, kb_id, query, response, scores } API -->>- User : 200 OK — EvalRecord with all 4 scores
